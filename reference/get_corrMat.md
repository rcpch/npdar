# Correlation Matrix with Plotly

Computes a correlation matrix and corresponding p-values, and visualises
the lower triangle as an interactive heatmap using plotly. Correlation
values and significance stars can be displayed inside each tile.

## Usage

``` r
get_corrMat(
  data,
  method = c("pearson", "spearman"),
  use = c("pairwise.complete.obs", "complete.obs", "everything", "all.obs",
    "na.or.complete"),
  digits = 2,
  show_stars = TRUE,
  show_values = TRUE,
  colors = c("#11A7F2", "#FFFFFF", "#E00087"),
  ...
)
```

## Arguments

- data:

  A data frame or matrix containing only numeric variables.

- method:

  Correlation method: `"pearson"` or `"spearman"`, passed directly to
  [`stats::cor()`](https://rdrr.io/r/stats/cor.html) and
  [`stats::cor.test()`](https://rdrr.io/r/stats/cor.test.html).

- use:

  Missing-data handling passed directly to
  [`stats::cor()`](https://rdrr.io/r/stats/cor.html). One of
  `"pairwise.complete.obs"`, `"complete.obs"`, `"everything"`,
  `"all.obs"`, or `"na.or.complete"`.

- digits:

  Number of decimal places for correlation labels.

- show_stars:

  Logical; display significance stars (\*, \*\*, \*\*\*) based on
  p-values.

- show_values:

  Logical; display correlation values inside tiles.

- colors:

  A vector of colours for the heatmap colour scale. Defaults to NPDA
  colours.

- ...:

  Additional arguments passed to
  [`plotly::plot_ly()`](https://rdrr.io/pkg/plotly/man/plot_ly.html).
  These can override default plotly arguments such as `showscale`, or
  `colorbar`.

## Value

A plotly heatmap object.
